# Marik — настольный робот-компаньон

Marik — школьный проект, вдохновлённый Desay Mochi. Идея проекта — сделать небольшого настольного персонажа, который показывает эмоции на OLED-экране и реагирует на прикосновения и движение корпуса.

## Текущее состояние

- При включении Marik открывает глаза, улыбается и один раз произносит «Привет! Я Марик, голосовой помощник и робот-компаньон» через I²S-усилитель. В ожидании он периодически моргает.
- После встряхивания Marik сердится, а после касания показывает радостное лицо с сердечками. По окончании реакции возвращается к обычной улыбке.
- Исходный прототип из `marik1.txt` сохранён ниже как отдельный пример для проверки дисплея.

## Комплектующие и подключение

Плата **ESP32-S3-Zero N4R2** (4 МБ флеш-памяти, 2 МБ PSRAM) управляет дисплеем и считывает сигналы с датчиков. [Документация платы](https://docs.waveshare.com/ESP32-S3-Zero)

| Модуль | Назначение | Сигнальные выводы ESP32-S3 |
| --- | --- | --- |
| Синий OLED 0,96″, 128 × 64 (SSD1306 по умолчанию) | Показывает лицо робота | I²C `Wire` — SCL → GPIO1, SDA → GPIO2 |
| Датчик движения (MPU-6050 или MPU-6500) | Измеряет ускорение и угловую скорость | I²C `Wire1` — SCL → GPIO5, SDA → GPIO6 |
| Сенсорная кнопка TTP223 | Регистрирует прикосновение | OUT → GPIO4, прямой режим, активный уровень HIGH |
| I²S-усилитель с динамиком | Воспроизводит приветствие | BCLK → GPIO8, LRC/WS → GPIO9, DIN → GPIO7 |

Соедините `GND` всех модулей с `GND` платы, а `VCC` TTP223 — с `3V3`. Для питания OLED и GY-521 от `3V3` проверьте, что конкретные модули поддерживают 3,3 В. Рабочий скетч использует две независимые шины I²C. [Две шины I²C на ESP32-S3-Zero](https://docs.waveshare.com/ESP32-Arduino-Tutorials/I2C-Communication)

## Запуск в Arduino IDE

1. Установите пакет плат **esp32 by Espressif Systems** через менеджер плат Arduino IDE. При необходимости добавьте `https://espressif.github.io/arduino-esp32/package_esp32_index.json` в поле дополнительных URL менеджера плат. [Инструкция Espressif](https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html)
2. Подключите ESP32-S3-Zero по USB, выберите профиль **ESP32S3 Dev Module** и порт платы. Если в настройках доступен пункт **Flash Size**, выберите **4 MB** для N4R2.
3. Установите **U8g2** через менеджер библиотек. Для MPU-6050 используется `Wire` из пакета плат ESP32. [Документация U8g2](https://github.com/olikraus/u8g2/wiki)
4. Подключите модули по таблице, откройте [marik.ino](src/marik/marik.ino) и загрузите скетч. Дождитесь улыбки, встряхните корпус и коснитесь кнопки. Если датчик движения не отвечает, включите **USB CDC On Boot** и откройте монитор порта на `115200` бод, чтобы увидеть сообщение при сбросе.

## Если OLED остаётся чёрным

Включите **Инструменты → USB CDC On Boot → Enabled**, загрузите скетч, откройте монитор порта на `115200` бод и нажмите **RESET**. Скетч проверяет адреса `0x3C` и `0x3D` на шине OLED с частотой 100 кГц.

- `OLED: no reply at 0x3C or 0x3D` — проверьте питание и общий `GND`, затем сверьте надписи на модуле: `SCL` идёт на `GPIO1`, `SDA` — на `GPIO2`. Порядок контактов на модуле может отличаться от порядка на плате.
- `OLED: I2C reply at 0x3C` или `0x3D` — модуль отвечает по I²C. Если экран всё ещё чёрный, проверьте модель контроллера по маркировке или описанию товара. Для `SH1106` установите `MARIK_OLED_SH1106` в `1` и загрузите скетч заново. [Драйверы дисплеев U8g2](https://github.com/olikraus/u8g2/wiki/u8g2setupcpp)

## Если Marik не реагирует на встряхивание

Откройте монитор порта на `115200` бод. После сброса скетч сообщает модель и адрес датчика, например `MPU-6500 ready at 0x68`. Отправьте `?`, чтобы увидеть текущие показания ускорения и гироскопа. Строка `Shake detected: angry face.` появляется при запуске анимации злости. Если датчик не отвечает, проверьте питание, общий `GND`, `SCL → GPIO5` и `SDA → GPIO6`.

<summary>Исходный пример с улыбкой</summary>

```cpp
#include <Arduino.h>
#include <U8g2lib.h>
#include <Wire.h>

#define I2C_SDA_PIN 2
#define I2C_SCL_PIN 1

U8G2_SSD1306_128X64_NONAME_F_HW_I2C u8g2(U8G2_R0, U8X8_PIN_NONE, I2C_SCL_PIN, I2C_SDA_PIN);

void setup() {
  Serial.begin(115200);
  u8g2.begin();
  u8g2.clearBuffer();
  u8g2.setDrawColor(1);

  u8g2.drawRBox(24, 16, 16, 24, 7);
  u8g2.drawRBox(88, 16, 16, 24, 7);

  // Два полудиска разного радиуса образуют контур улыбки.
  u8g2.setClipWindow(46, 45, 82, 64);
  u8g2.drawDisc(64, 45, 12);
  u8g2.setDrawColor(0);
  u8g2.drawDisc(64, 45, 7);
  u8g2.setMaxClipWindow();
  u8g2.setDrawColor(1);

  u8g2.sendBuffer();
  Serial.println("Smile with 5px outline!");
}

void loop() {}
```
